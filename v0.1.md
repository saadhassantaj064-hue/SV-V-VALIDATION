# SRS Checklist v0.1 (MediTrack)

Rule: "Yes" is always the good answer. Each item is one question, can be checked by reading the SRS, and has one clear meaning.

Sources: Rule = rule of a good document, Risk = clinic risk, User = what a user would look for.

Risks used: R1 double booking, R2 patients forget appointments, R3 private medical data, R4 elderly and emergency walk-ins left out, R5 busy Monday mornings.
